# Selenium + Java + Cucumber Automation Testing

## Project Overview

A personal QA automation practice project demonstrating web form testing using Selenium WebDriver, Java, Cucumber, JUnit, and Maven.

## Technologies Used

* Java
* Selenium WebDriver
* Cucumber (BDD)
* JUnit
* Maven
* Chrome browser

## Test Scenario

1. Open the Selenium practice web form.
2. Enter text into the text box.
3. Submit the form.
4. Verify the confirmation message `Received!`.

## How to Run

Ensure Java and Maven are installed, then run this command from the project directory:

```bash
mvn clean test
```

## Test Report

The HTML Cucumber report is configured at `target/cucumber-reports.html`.

## Purpose

This is a personal learning and portfolio project, not employer-owned or production code.
